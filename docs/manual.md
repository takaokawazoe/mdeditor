# メモ帳の使い方

## 画面の見方

| 場所 | 内容 |
| --- | --- |
| サイドバー | メモの一覧（並びは自由に入れ替え可）。上に「すべてのメモを検索」、下に保存先 |
| 上部バー | ＜ ＞（サイドバーを隠す／表示。スマホは☰）、現在のメモのタイトル、↶ ↷（元に戻す／やり直す）、鍵（ロック）、検索、ファイル、Markdownを表示 |
| 編集エリア | 行をクリックすると、その行だけ元のMarkdownが現れて編集できる |

左上の「＜」かCtrl/⌘+`\`でサイドバーを隠せます。隠すとボタンが「＞」に変わり、押すと戻ります（隠した状態は次に開いたときも続きます）。スマホなど画面が狭いときは「☰」でサイドバーを開閉し、上部バーの操作は「…」にまとまります。

## 基本の書き方

| 書きたいもの | 書き方 | 補足 |
| --- | --- | --- |
| 見出し | `# 見出し`（`#`は1〜6個） | 最初の行がメモのタイトルになる |
| 箇条書き | `- 項目` | Enterで次の項目。空の項目でEnterすると抜ける |
| 番号付き | `1. 項目` | 番号は表示時に1から振り直す。`1.` だけで書いてもよい |
| チェックボックス | `- [ ] やること` | 四角をクリックで切り替え |
| 太字 | `**文字**` | Ctrl/⌘+B |
| 斜体 | `*文字*` | Ctrl/⌘+I |
| コード | `` `文字` `` | Ctrl/⌘+E |
| 取り消し線 | `~~文字~~` |  |
| リンク | `[文字](https://…)` | Ctrl/⌘を押しながらクリックで開く |
| 引用 | `> 文章` |  |
| コードブロック | ```` ``` ```` で囲む | 中ではEnterが改行。閉じの ```` ``` ```` の行末でEnterで抜ける |
| 区切り線 | `---` |  |

- Ctrl/⌘+B（太字）・I（斜体）・E（コード）は切り替えです。文字を選んでから押すとその部分を囲み、もう一度押すと囲みが外れます。何も選ばずに押すと記号だけが入り、そのまま打てます
- 箇条書きの中でTab：字下げ。Shift+Tabで戻す。番号付きは字下げすると `1.` から
- Shift+Enter：同じ行の中で改行
- 行頭でBackspace：前の行とつなぐ
- Esc：編集をやめる。そのあとEnterで同じ場所に戻ります。↑↓←→を押すと、カーソルがそのまま動いたように上下の行や前後の文字へ入ります（マウスは要りません）

## 表の書き方

`| 名前 | 点数` と書いてEnterを押すと、行末の `|` と区切り行 `| --- | --- |` が自動で入り、次の行が `| ` で始まります。あとはセルを `|` で区切りながら書き、Enterで次の行へ。行頭に `|` だけの状態でEnterを押すと表を抜けます。

- Tab／Shift+Tab：次／前のセルへ。最後のセルでTabするとセルを追加
- 編集を終えると縦線が揃うよう自動で整形
- 区切り行を `:---` `:---:` `---:` にすると左寄せ・中央・右寄せ
- セルの中に `|` を書くときは `\|`

## 検索と置換

**このメモ内**：上部の「検索」か Ctrl/⌘+F。Ctrl/⌘+H で置換欄も開きます（バー内の「置換」でも切り替え）。

- Aa：大文字と小文字を区別、.*：正規表現
- Enter／↓で次、Shift+Enter／↑で前。該当する行は薄く色が付き、いま見ている一致はその行の元のMarkdownの中で反転
- Esc：閉じて、その一致箇所を選択した状態で編集に入る
- 置換：1件ずつ（置換後は次へ進む）。すべて置換：一括。Undoで戻せる。正規表現なら `$1` で捕捉した文字を使える

**すべてのメモ**：サイドバー上の検索欄（Ctrl/⌘+Shift+F）。該当するメモだけが件数と抜粋つきで並びます。3件まで表示し、「さらに表示」で残りを開きます。クリックするとそのメモが開き、同じ検索語がメモ内検索に引き継がれます。

## 行の選択

編集中の行でShift+↓（行末側）／Shift+↑（行頭側）を押すと、行単位の選択が始まります。続けてShift+↑↓で範囲を伸ばしたり縮めたりできます。

- Ctrl/⌘+C：選択した行のMarkdownをコピー
- Ctrl/⌘+X、Backspace、Delete：選択した行を削除
- Tab／Shift+Tab、Alt+Shift+→／←：選択した行をまとめて字下げ／戻す
- Alt+Shift+↑／↓：選択した行をまとめて上下に移動
- 文字を打つ、Enter：選択行を消してその場で入力を始める
- Esc、矢印キー、クリック：選択を解除
- Ctrl/⌘+A：メモの全行を選択（そのままCtrl/⌘+Cで全体をコピー）

行の途中から別の行の途中まで、という文字単位の選択はできません。

## メモの管理とロック

- 新しいメモ：「＋ 新しいメモ」（一覧の先頭に入ります）
- 並べ替え：一覧の項目をドラッグして好きな位置へ。スマホでは項目を長押しして持ち上げてから指を動かす（端まで運ぶと一覧がスクロール）。更新しても並びは変わりません
- 削除：一覧の項目にマウスを乗せて「×」→「削除する」
- ロック：上部の鍵をクリック。ロック中は本文を編集・削除できません。閲覧・検索・コピー・.md保存はできます。もう一度クリックで解除
- 元に戻す／やり直す：↶ ↷、Ctrl/⌘+Z、Ctrl/⌘+Shift+Z（Ctrl+Y）。履歴はメモごと
- Markdownを表示：メモ全体を生のMarkdownとして表示・編集
- ？：この使い方を開く（削除されていれば入れ直す）

## ファイルの読み込みと書き出し

上部バーの「ファイル」（スマホは「…」）にまとまっています。1ファイル＝1メモです。

| メニュー | すること |
| --- | --- |
| 指定したファイルを開く | 選んだ.md／.txt（複数可）をメモとして追加 |
| .zip内のすべての.mdを開く | .zipの中の.mdをすべてメモとして追加（書き出した控えを戻すとき） |
| フォルダ内のすべての.mdを開く | 選んだフォルダの.mdをすべて一度だけ読み込む（Chrome/Edge） |
| このファイルを.mdで保存 | 表示中のメモを.mdファイルとしてダウンロード |
| すべてのファイルを保存 → フォルダへ書き出し | 選んだフォルダに全メモを `タイトル.md` として一度だけ書き出す（Chrome/Edge） |
| すべてのファイルを保存 → .zipで保存 | 全メモを1つの.zipにまとめる。スマホでは共有シートが開くので、ファイルアプリやクラウドにそのまま送れる |

- .mdや.txt、.zipを画面にドラッグして落としても追加できます
- すでに同じ内容のメモがあるファイルは飛ばします。控えを読み直しても二重になりません
- フォルダへの書き出し・読み込みは一回きりで、そのフォルダを保存先にはしません
- スマホの「…」には「すべてをコピー」もあり、表示中のメモのMarkdownをまるごとクリップボードへ送れます

## 保存先

最初に開いたとき（Chrome/Edgeでパソコンに置いたHTMLを開いた場合）に、保存先を選ぶ画面が出ます。

- ブラウザに保存：このブラウザの中に保存。ファイルは作らない。最後の変更から0.4秒後に自動保存
- フォルダに保存：選んだフォルダに各メモを `タイトル.md` として保存。最後の変更から0.7秒後に書き戻し。最初の行を変えるとファイル名も追従、削除するとファイルも消える。フォルダに他のエディタで.mdを追加すると「再読み込み」で取り込む

いまの保存先はサイドバー下に「ブラウザ（ローカルストレージ）」または「ローカルPC（フォルダ名）」と出ています。「保存先の切り替え」で変えられます。

- ブラウザ → ローカルPC：フォルダを選ぶと、いまのメモをそのフォルダに書き出し、フォルダにある.mdも読み込みます
- ローカルPC → ブラウザ：「切り替える」を押すと、以後はブラウザに保存します。メモはブラウザに残り、フォルダの.mdも消えません

ブラウザを開き直したときなどにフォルダへの許可が切れていると、再接続を促す画面が出ます。「接続する」で保存を再開します。「あとで」を選ぶとサイドバー下に「未接続」と出て、接続するまで変更はブラウザにだけ残ります（接続したときにフォルダへ反映します）。

フォルダ保存はChrome/Edge限定で、Claude上の公開版・Firefox・Safari・スマホでは「保存先の切り替え」は出ません。ブラウザの閲覧データを消すとブラウザ内のメモは消えるので、大事なものはフォルダ保存か、「ファイル」→「すべてのファイルを保存」で控えを。

**フォルダ保存中に食い違ったとき**：ブラウザ側と.mdファイルの両方が変わっていたら、更新が新しいほうを残し、負けたほうを「○○（ブラウザ側の写し）」「○○（フォルダ側の写し）」という別のメモにします。どちらの内容も消えません。

## ショートカットキーの変更

左上の「⚙」→「キーボード」で、ショートカットキーを変えられます（このブラウザにだけ保存されます）。

| 操作 | 場面 | 既定 |
| --- | --- | --- |
| このメモ内を検索／置換／すべてのメモを検索 | いつでも | Ctrl/⌘+F／+H／+Shift+F |
| 元に戻す／やり直す | いつでも | Ctrl/⌘+Z／+Shift+Z |
| サイドバーの表示 | いつでも | Ctrl/⌘+`\` |
| 保存 | いつでも | Ctrl/⌘+S |
| 全行を選択 | いつでも | Ctrl/⌘+A |
| 太字／斜体／コード | 編集中 | Ctrl/⌘+B／+I／+E |
| 取り消し線 | 編集中 | （なし） |
| 引用の付け外し | 編集中・行選択中 | （なし） |
| リンクの挿入 | 編集中 | （なし） |

- 「変更」を押してから、割り当てたいキーを押します。Escでやめられます
- 「なし」で割り当てを消せます。「既定」でその行だけ元に戻り、右上の「すべて既定に戻す」で全部戻ります
- すでに使われているキーを押すと、その場では変わりません。もう一度同じキーを押すと、そちらへ移ります
- Enter・Tab・Esc・Backspace・矢印キーは本文の操作に使うので割り当てられません。修飾キー（Ctrl/⌘・Alt・Shift）との組み合わせだけが使えます
- Ctrl+TやCtrl+Wなど、ブラウザが先に使うキーは効かないことがあります
- 取り消し線・引用・リンクは、キーを割り当てると使えるようになります。リンクは、文字を選んでいれば `[選んだ文字]()` にしてURLの位置にカーソルが入り、選んでいなければ `[]()` を入れて文字の位置から書き始められます（続けてもう一度押すと取り消せます）
- 画面が狭いときは、この設定は表示されません

## 困ったときは

- 書式が効かない：`#` や `-` のあとに半角スペースが必要です
- 表にならない：見出し行の次に `| --- | --- |` の区切り行が必要です。`|` や `-` が全角になっていないか確認してください
- 「保存先の切り替え」が出ない：ChromeかEdgeで、パソコンに置いたHTMLを直接開いているか確認してください
- フォントが違って見える：オフラインではWebフォントが読めず、端末の標準フォントで表示されます
